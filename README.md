MSC is an Electron desktop application developed using HTML, CSS, and JavaScript. It uses the TMDB API to search for movies, recommend movies based on genres and ratings, and manage a personal watchlist.

How to Run

Download the project from GitHub (Code → Download ZIP).

Extract the ZIP file.

Open the project folder in VS Code.

Open the terminal and install dependencies:

npm install

Start the application:

npm start

Note: An internet connection is required to retrieve movie information from TMDB.
